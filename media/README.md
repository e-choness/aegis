# Aegis media

The single home for brand and media assets. Edit files here, not copies.

| File | Used by |
|---|---|
| `logo.svg` | docs site logo/favicon and home hero (synced to `docs/public`) |
| `social-preview.png` | Open Graph image (synced to `docs/public`); rendered from `banner-media.svg` |
| `banner-wide.svg` | README banners |
| `banner-media.svg` | source for `social-preview.png` |
| `terminal-demo.svg` | README and docs home; generated by `scripts/gen-terminal-demo.cjs` |
| `fonts/` | Montserrat Alternates Bold (OFL), the Aegis **title** font |

## Title font

Titles (the AEGIS wordmark, page h1, hero headings, the showcase header) use
[Montserrat Alternates](https://fonts.google.com/specimen/Montserrat+Alternates) Bold.
Subtitles, descriptions and body text keep Inter / system fonts.

- SVGs render as `<img>` on GitHub and cannot load fonts, so the wordmark is
  **outlined to a path** (`#wordmark`) rather than left as `<text>`.
- The docs site self-hosts `fonts/MontserratAlternates-Bold-latin.woff2`;
  `scripts/sync-media.mjs` (run by the `docs:*` npm scripts) copies it, the logo
  and the social preview into the git-ignored parts of `docs/public`.
- `packages/aegis-server/.../static/showcase.html` embeds the same woff2 as base64.
